# **2D Game - "ANT ATTAK"**

A 2D Game Developed in Processing where the aim is to protect the cake from the incoming ants and bees. The player can prevent them from eating the cake by swatting them with the fly swat (mouse click) or if they are eating the cake, clicking the cake to get rid of them all.

This project was developed as coursework for the Programming module at university. I achieved a mark of 95%. All the programming and artwork has been created by me.
