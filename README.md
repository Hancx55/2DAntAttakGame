# **2D Game - "ANT ATTAK"**

A 2D Game Developed in Processing where the aim is to protect the cake from the incoming ants and bees. The player can prevent them from eating the cake by swatting them with the fly swat (mouse click) or if they are eating the cake, clicking the cake to get rid of them all.

This project was developed as coursework for the Programming module at university. I achieved a mark of 95%. All the programming and artwork has been created by me.

## Tech Stack:
- Java
- Processing

## Game Features:
- Fully animated enemies with direction-based movement
- Cake health bar updates in real time
- Multiple enemy types with different movement patterns
- Several different game menus
- Functional Leaderboard with name entry
- Mouse controlled fly swatter mechanic
- Cake click mechanic clears all enemies currently eating it

## Technical Features:
- Class structure utilises encapsulation, inheritance, polymorphism and abstraction
- Event-driven input handling with mouse interactions and keyboard text entries
- Frame-based dynamic enemy spawning
- Leaderboard with file input, output and  string parsing
- bubble-sort ranking system
- Central game loop managing updates, collisions and rendering
- Collision detection using vectors
- Easy to navigate menu system
- Polymorphic enemy system using Enemy superclass with specialised subclasses

## How To Play:
1. Download/clone this repository
2. Open a .pde file in Processing

4. Play through the game
